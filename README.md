# MIDNIGHT Chat Skills

Public distribution of qualified MIDNIGHT skill protocols for ordinary GPT Chat sessions.

## Start here

Read `GPT_CHAT_LOADER.md`, then load only the skill needed for the current task.

This repository is a distribution surface, not the private MIDNIGHT control plane. Reading these files does not create native ChatGPT installation, automatic cross-chat activation, background execution, or permission to modify private MIDNIGHT systems.

Current stable release: `skills-2026.10.05.1`.

## Included

- `find-skills`
- `grill-me` and dependency `grilling`
- `impeccable` safe core
- `skill-creator`
- `midnight-auto-advance`

The Humanizer, Fact Checker, Prompt Master, and MCP Builder adaptations remain excluded until their qualification is complete.
